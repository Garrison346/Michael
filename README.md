# Michael - Autonomous Fire Detection Robot 🤖🔥

Michael is an autonomous robotics project designed for real-time fire and smoke detection using computer vision and edge computing.

---

## 🛠️ Tech Stack & Hardware
* **Hardware:** Raspberry Pi (8GB)
* **Computer Vision:** YOLO (Ultralytics)
* **Environment:** Python 3, OpenCV
